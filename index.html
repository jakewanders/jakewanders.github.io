Summary

Full-stack JavaScript engineer who has spent a decade on the front end and the services behind it, and the last few years on a different problem: how to make AI-assisted development reliable enough to run unattended.

I build the harnesses, MCP servers, and skills that turn a capable model into a dependable teammate — scoped tools, deterministic orchestration, verification gates, and runbooks a human can audit. I care about the boring parts: clear interfaces, small well-bounded units, and systems you can reason about at 2 a.m.

AI-assisted engineering

Work across the software development lifecycle, delivered as reusable agent infrastructure rather than one-off prompts.

  • MCP server. Designed and built a Model Context Protocol server exposing internal systems as typed, scoped tools so agents can act on real data with least-privilege access and auditable calls.
  • Custom skills library. Authored a suite of skills that package repeatable engineering workflows — brainstorming and spec-writing, plan execution, TDD loops, code review, release and deploy runbooks — so an agent picks the right procedure instead of improvising.
  • Harness engineering. Built orchestration that fans work out to parallel subagents, routes results through adversarial verification, and gates merges on evidence rather than assertions. Designed for resumability and cheap failure.
  • Multi-agent systems in production. Architected an event-driven trading system that routes live news through a five-agent LLM pipeline into structured signals, with layered risk controls and circuit breakers. Case study →
